# Smof

Smof (Donut Smof) это собственный рабочий стол на Arch Linux: оболочка, приложения, установщик и обновления в одном образе. Идея в том, чтобы поставить систему на обычный старый ноутбук и пользоваться ею каждый день, не открывая терминал.

Стиль: Material 3 с оглядкой на macOS, стекло и размытие, длинные плавные анимации. Всё, что видно на экране, от панели до экрана входа, нарисовано на QML и запускается как отдельные приложения.

## Статус

Ранняя альфа. Основная проверка шла в виртуальной машине, живой образ запускался на одном реальном ноутбуке. Для повседневной работы пока не готова.

Проверено в виртуальной машине: первый запуск и вход, окна, тайлинг, рабочие столы, анимации, поиск, настройки, Wi-Fi, ночной свет, запись и снимки экрана. Живой образ x86_64 загружается на реальном ноутбуке, но полный путь от первого запуска до повседневной работы там ещё не пройден.

Что ещё не проверено на реальном железе или не доделано:
- установка на жёсткий диск рядом с Windows: установщик написан, но на настоящем диске его ещё не запускали
- кнопка Update Smof и смена пароля в настройках на реальном ноутбуке
- Bluetooth: на тестовом ноутбуке не заработал, причина не найдена
- нет шифрования диска, брандмауэра, печати, почты, офиса, просмотрщиков PDF и картинок
- нет сохранения энергии для ноутбука: батарея пока тратится как у обычной системы без настройки
- демонстрация экрана в браузерах и звонках не настроена

Система развивается быстро, всё может ломаться и меняться. Данные на диске, на который вы ставите Smof, лучше сохранить заранее.

## Что внутри

База: Arch Linux, ядро и пакеты из репозиториев Arch.

Композитор: Wayfire. На нём работают плагины для окон: рамки (`pixdecor`), скруглённые углы и тени (`rounded-corners`, наша версия), плавное изменение размера и положения окон (`smooth-geometry`, наш плагин), размытие, рабочие столы, обзор.

Оболочка: Quickshell, интерфейс на QML. Отдельные приложения:

| Приложение | Что делает |
|---|---|
| `greeter` | экран входа и первый запуск |
| `bar` | верхняя панель и центр управления |
| `dock` | док |
| `launcher` | поиск и запуск программ, поиск по смыслу, история буфера обмена |
| `settings` | настройки: оформление, обои, экран, окна, клавиатура, уведомления, сеть, Bluetooth, ночной свет, откат по времени, обновление, учётная запись |
| `files` | файлы |
| `store` | магазин приложений |
| `wallpaper` | обои |
| `notifd` | уведомления |
| `auth` | запрос пароля |
| `upscaler` | увеличение картинок на нейросети |

Инструменты в `base/vm` с названиями `smof-*`: установщик, тайлер, снимки и запись экрана, ночной свет, Wi-Fi и Bluetooth, обновление и так далее.

Поиск по смыслу работает на локальной модели multilingual-e5-small, ничего никуда не отправляется. Индекс строится в фоне с низким приоритетом.

Из чужого в образе: Firefox, VLC, терминал foot, PipeWire, NetworkManager, Mesa. Шрифт Google Sans Flex.

## Как попробовать

Готовые образы выкладываются в [релизах](https://github.com/VibeCoder-sudo/smof-os/releases) как предварительные версии. Образ весит около 2 ГБ. Он загружается в живом режиме, без установки, нужен компьютер x86_64 с UEFI. В живом режиме система и все изменения хранятся в оперативной памяти, поэтому на машинах с небольшим объёмом памяти возможны проблемы. Способ записи на флешку мы отдельно не проверяли, на тестовом ноутбуке образ запускался с раздела жёсткого диска.

## Как собрать образ

Нужна машина на Arch Linux x86_64 или контейнер Arch:

```bash
sudo bash base/iso/build.sh
```

Готовый образ появится в `base/iso/out/`. Сборка тянет пакеты из репозиториев Arch, модель для поиска и собирает наши плагины для Wayfire под текущий процессор.

В облаке: GitHub Actions, workflow `build-smof-iso`, запускается вручную. Занимает около 25 минут. Образ потом лежит в артефактах 14 дней.

Список пакетов образа: `base/iso/packages.txt`. Файлы, которые накладываются на систему, лежат в `base/iso/overlay/`.

## Как устроены обновления

У нас есть свой репозиторий пакетов в формате pacman. Он лежит в релизе `repo`, и в нём один пакет `smof-shell`: весь рабочий стол и инструменты. Его пересобирает workflow `build-smof-repo`, когда меняются файлы в `base/shell`, `base/vm`, `base/assets` или `base/pkg`.

В настройках на странице обновления система проверяет базу `smof.db` и, если версия новее, скачивает пакет, проверяет размер и контрольную сумму и ставит его. Подписи пакетов пока нет, репозиторий подключён с `SigLevel = Optional TrustAll`. Это временное решение, подпись планируется.

Само ядро и пакеты Arch обновляются обычным `pacman -Syu`.

## Устройство репозитория

```
base/
  assets/    обои, иконки, звуки, шрифты, бренд
  iso/       сборка живого образа, список пакетов, файлы поверх системы
  pkg/       пакет smof-shell и сборка репозитория
  shell/     QML: экран входа и все приложения
    shared/  общие компоненты, копируются в каждое приложение
  sr/        увеличение картинок на нейросети
  vm/        инструменты smof-*, плагины Wayfire, конфиг Wayfire
.github/workflows/   сборка образа, репозитория, публикация релиза
```

## Разработка

Основная проверка идёт на виртуальной машине Arch ARM, потому что разработка ведётся на Mac. Рабочий стол не зависит от архитектуры, а плагины Wayfire и образ собираются на x86_64.

Каждому QML-приложению нужна своя копия общих файлов из `base/shell/shared`, потому что Quickshell не умеет импортировать их снаружи папки приложения. Для этого есть `base/shell/deploy.sh` и такой же шаг в сборке.
